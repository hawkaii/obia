obia
terminal TUI for your Obsidian vault · now with AI context

⚡ What it is

obia is a Go TUI (Bubble Tea) that turns your Obsidian vault into a live task dashboard. It scans every - [ ] checkbox across all your markdown files and presents them in a vim-navigable terminal interface with tabs, filters, CalDAV sync, and — new — a Hermes AI context briefing.

🚀 Features

📋

Task Management

Parse, toggle, add, and edit - [ ] tasks from any .md file

📁

Configurable Tabs

Filter by folder, tag, wikilink, time window, rolling dates, overdue, and more

🔄

CalDAV Sync

Push/pull VTODOs with any CalDAV server (Nextcloud, iCloud, etc.)

🧠

Hermes Context

NEW Session briefing on startup — last logs, DSA progress, uncommitted changes

💬

Chat Mode

NEW Press c to chat with Hermes about your session

⚡

Instant Startup

Stale-while-revalidate cache loads tasks in milliseconds

⌨️ Keybindings

  ↑/k  ↓/j   Navigate
  Enter       Toggle task
  a           Add task
  e           Edit task
  c           NEW Chat mode (ask Hermes about context, DSA, etc.)
  p           Push to CalDAV
  R           Pull from CalDAV
  /           Filter
  v           Toggle grouped view
  Tab/⇧Tab   Switch tabs
  Ctrl+g      Open in $EDITOR
  r           Reload vault
  q           Quit

📦 Install

# Clone
git clone https://github.com/hawkaii/obia.git
cd obia

# Build
go build -o obia .

# Configure
mkdir -p ~/.config/obia
cat > ~/.config/obia/config.toml << 'EOF'
[vault]
path = "/mnt/d/obsidian/your-vault"

[hermes]
endpoint = "http://your-hermes-vm:4123"
repo = "current-project"

[ui]
tabs = [
  { name = "Today", filter = "timewindow", window = "day" },
  { name = "Week", filter = "timewindow", window = "week" },
  { name = "Open", filter = "open" },
  { name = "Overdue", filter = "overdue" },
]
EOF

# Run
./obia

🧠 Hermes Integration

obia connects to the Hermes Context API — a lightweight Node.js server that runs on your Hermes VM. On startup, obia fetches:

  • 📋 Your last session logs from the vault
  • 🔨 Recent commits from your GitHub repos
  • 🏋️ DSA streak and next CSES problem
  • 📦 Uncommitted changes in your repo

All presented as the default Context tab — zero manual input needed.
